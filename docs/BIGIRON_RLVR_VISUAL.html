Training Pipeline

Phase 1: Data Collection

✓ Complete • 120,414 examples
Hand-crafted code examples, IBM Redbooks extraction (30,799 Q&A pairs), MainframeBench integration, agentic training data.

Phase 2: Supervised Fine-Tuning (SFT)

⏳ In Progress • ~40 hours remaining
Full fine-tuning of all 7.2B parameters on Apple Silicon using MLX framework. Teaches patterns and syntax from examples.

Phase 3: RLVR Training

⏳ Queued • ~10-20 hours estimated
Reinforcement learning with real MVS verification. Model generates code, submits to TK5, learns from actual condition codes. Trains until 10 consecutive CC 0000.

Phase 4: Deployment

⏳ Pending
Convert to GGUF, register with Ollama, publish to HuggingFace. Model writes JCL/COBOL that actually runs on MVS 3.8j.
